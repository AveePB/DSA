# 32. Longest Valid Parentheses
Given a string containing just the characters '(' and ')', return the length of the longest valid (well-formed) parentheses substring.

### Example 1
**Input**: s = "(()" <br>
**Output**: 2 <br>
The longest valid parentheses substring is "()". <br>

### Example 2
**Input**: s = ")()())" <br>
**Output**: 4 <br>
The longest valid parentheses substring is "()()". <br>

### Example 3
**Input**: s = ""<br>
**Output**: 0<br>

## Constraints:
-	0 <= s.length <= 3 * 104
-	s[i] is '(', or ')'.
